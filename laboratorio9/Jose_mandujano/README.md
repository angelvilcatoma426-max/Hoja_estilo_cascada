# MotionLab - Laboratorio de Animaciones CSS (Semana 9)

## Descripción
MotionLab es una interfaz web interactiva que demuestra el uso accesible de animaciones CSS (`@keyframes`, `animation-*`) mediante controles nativos sin JavaScript.

## Características
- Entrada escalonada de tarjetas (0ms, 120ms, 240ms, 360ms).
- Controles de activación y pausa con checkboxes y selectores de hermano posterior (`~`).
- Respeto total a la preferencia del sistema `prefers-reduced-motion: reduce`.
- Componentes totalmente usables en estado estático.

## Instrucciones de Ejecución
1. Abrir la carpeta raíz `motionlab` en Visual Studio Code.
2. Servir el archivo `index.html` utilizando la extensión **Live Server** o un servidor HTTP local.
