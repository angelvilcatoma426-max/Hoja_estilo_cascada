Dos sintaxis de autoría

Sass · SCSS

Variables con $. El módulo y los mixins se procesan antes de que el navegador reciba el archivo.

$color-primary: #0b67d1;

Less

Variables con @. La compilación también produce CSS estándar y puede generar un mapa de origen.

@color-primary: #0b67d1;

CSS generado

El contrato del navegador. La pestaña Network debe cargar una salida desde dist/css, nunca el archivo fuente.

color: #0b67d1;

Criterio profesional

La compilación debe poder repetirse.

Conserva package.json, package-lock.json y las fuentes. Documenta versiones, comando, resultado y corrección.
